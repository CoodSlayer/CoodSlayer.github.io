Systems and tools

Modifier system
MMORPG-style stat modifiers: stacking, timed buffs and debuffs, priority ordering and several calculation types. Designers create new effects through configuration. Built in Dragon Trainer and reused in later titles.
ECS and abilities
An entity-component architecture with a gameplay ability system on top, built for Smack Stars. Roblox has no built-in ECS, so the framework was written from scratch.
Editor tools for artists
Plugins that flag models for optimization and create lighting profiles. Work that needed a developer now takes artists a few clicks.
Quest tracker and data layers
A quest tracker first built for Polybattle and used in four of the five titles, plus abstraction layers for client-server data exchange.
